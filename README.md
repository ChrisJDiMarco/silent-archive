# The Silent Archive

Playable three-chapter alien-language puzzle. Six inferable words, two distractor meanings, contextual evidence, editable lexicon, immediate translation feedback, hints, and a final archive activation.

## Asset provenance and remaining request gap
The 3D relic is custom procedural Three.js geometry created for this prototype. It is NOT generated by Meshy or Tripo. Neither generator is callable through this session's tools and no corresponding credential is supplied. Public Meshy previews were inspected as a material reference, but no Meshy asset is bundled. Completing the original model-provider requirement needs an authorized Tripo/Meshy generation route or an exported model supplied by the owner.

Reference: https://www.meshy.ai/3d-models/Arcane-Obelisk-v2-0195252d-9a32-73c2-aecf-99ac5ed74dc4
Three.js 0.180.0 vendored with MIT license. Fonts: DM Sans and Space Grotesk via Google Fonts, falling back to system sans-serif.

## Run and validate
Serve dist as static files. `node check.mjs` checks all chapter solutions and evidence coverage. `node qa/verify.mjs` exercises the complete game in a headless browser against http://127.0.0.1:4317.

Verified locally: desktop and mobile pixels, WebGL initialization, incomplete/wrong/correct responses, all three chapters, ending, buttons for rotation, evidence selection, help dialog, mobile touch, reduced-motion preference, missing WebGL fallback. These are local checks; they do not establish the owner's native browser after-state. WebMCP is optional and feature-detected, but not verified in a native supporting context.

The game intentionally keeps progress in memory for this short session; reloading starts a new playthrough. No accounts or backend needed.
