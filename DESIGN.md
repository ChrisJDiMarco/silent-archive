# The Silent Archive

Outcome: decipher six alien words through contextual evidence, infer word order, and translate three progressively longer inscriptions to recover the archive's final message.
Audience: curious player; no prior linguistics knowledge.
Core idea: an archaeologist's working table beside a physically inspectable archive.
Visual thesis: smoked graphite, warm ivory text and amber instruments; large 3D relic at left, disciplined observation/transcription workspace at right.
Reference: https://www.meshy.ai/3d-models/Arcane-Obelisk-v2-0195252d-9a32-73c2-aecf-99ac5ed74dc4 — inspected actual preview; worn material and clear sculptural silhouette help object reading. Borrow material contrast, not shape or texture. Actual Meshy export pending authenticated access. Do not label a procedural object Meshy-generated.
Signature interaction: orbit the relic to find three evidence sites; equivalent labeled controls support keyboard/touch.
Motion: object inspection -> contextual evidence -> word hypotheses -> translation -> warm activation and final reveal. Reduced motion stops idle animation and uses immediate state changes. Pause when hidden.
Scope: one static route, Three.js only; no login, backend, arbitrary AI chat, or account changes.
Verification: game rules self-check, local asset and syntax checks; inspect desktop/mobile render if permitted. Owner-only Sites delivery.
